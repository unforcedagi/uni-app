# Uni release pipeline

Run on uni-1 from the dedicated clean `pipeline` worktree: `scripts/publish.sh`. Install the durable user timer with `bash scripts/install-updater-timer.sh` (uni-1 has systemd linger enabled); `scripts/watch-journal.sh` polls `origin/journal` every 30 minutes and publishes only when a non-release commit landed after the latest `uni-v*` tag. Inspect with `systemctl --user status uni-updater.service` and `journalctl --user -u uni-updater.service`; a failed build leaves the old manifests live and retries on the next tick. The publisher holds an exclusive lock so overlapping builds cannot race.
The script rebases on `origin/journal`, runs TypeScript/tests/case collision and Rust workspace tests, increments all semver fields plus Android versionCode, commits and tags, and pushes without force. It builds Android locally and Mac on `uni@100.126.18.24` from the exact pushed SHA (including the matching `../buzz` dependency). It publishes versioned signed updater artifacts and an atomic `mac/latest.json` pointer, `uni.apk` and `android/latest.json` under the existing tailnet-only Tailscale Serve directory. It also creates a private GitHub Mac prerelease containing the zip for first installs. Logs are under `$TMPDIR/uni-release-<version>/` (scratch is periodically pruned).

**Mac first install:** Aaron downloads the newest private `mac-v*` GitHub prerelease zip, unzips, copies `Uni.app` to `/Applications`, then runs `xattr -dr com.apple.quarantine /Applications/Uni.app` once. Sign in as the same identity. Thereafter on launch and about every six hours Uni downloads signed updates from `https://uni-1.taildf9ce2.ts.net:8443/mac/latest.json`, then offers **Update ready — Restart** without interrupting a conversation. The Mac must remain on the tailnet. The zip is ad-hoc-signed, not notarized; app migration does not require an Apple Developer account, but a true macOS Gatekeeper assessment of downloaded updates has not yet been verified. Do not claim absence of quarantine until tested on Aaron's MacBook.

**Daylight:** `https://uni-1.taildf9ce2.ts.net:8443/android/latest.json` advertises `https://uni-1.taildf9ce2.ts.net:8443/uni.apk`. While running, the app checks on launch and six-hour intervals; if newer, it offers **Download APK** through Android's browser/package installer (user confirmation is required). For zero-touch upgrades, if wireless ADB is online and Uni is *not* foreground, the script runs `adb install -r`; it never uninstalls. The current Android artifact is a **debug APK signed with uni-1's debug key**; replacing the key or installing a release-signed APK over it will fail and must not be worked around by uninstalling (would lose identity). Keep the existing `~/.android/debug.keystore` safe. Android's unknown-apps browser permission may require one-time approval.

Signing key: `~/.config/uni/updater/uni.key` (mode 600 on both build hosts), public key embedded in `tauri.conf.json`. Never commit/print/share the private key. Rotate only with a planned first-install migration. macOS updater tarball and detached minisign `.sig` are generated by Tauri using this key. New versions must increase patch and Android versionCode; never publish an older/latest.json pointer. Check manifests with `curl -fsS .../mac/latest.json` and `.../android/latest.json`, validate signature and URL; inspect logs on failures. Private GitHub release assets cannot be used directly as updater URLs without auth, hence the tailnet Serve endpoint.
