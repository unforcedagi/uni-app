## Uni 0.3.7

Cards that need your tap show up while the app is open, and releases now wait for your tap.

- **A waiting card is not lost.** While the app is open, a card that needs your tap shows even if a read fails or the connection drops; a failed sync is tried again on its own.
- **GitHub cards lead with the broker's words.** A GitHub ruleset card's first line now says which repo and what the call can do, in the broker's words, as Cloudflare cards already did.
- **Releases wait for you.** From this release on, the Android app is signed only after you approve one card, "Sign Uni X.Y.Z for Android". The signing key moves into the broker.
- **Less to load.** The home no longer reads the retired Today roll-up.
